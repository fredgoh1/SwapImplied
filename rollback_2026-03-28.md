## How to roll back

### Option A — Roll back only the two pipeline scripts (recommended)
Restores `calculate_swap_implied_rates.py` and `post_to_roam.py` to pre-change state.
The `output_master_*m.xlsx` files keep `Hedging_Cost_bps` — that's harmless since the old scripts ignore unknown columns.

```bash
git checkout a7bf1e3 -- calc_swap_implied/calculate_swap_implied_rates.py post_to_roam.py
git commit -m "Rollback: revert calculate_swap_implied_rates.py and post_to_roam.py to pre-2026-03-28"
```

### Option B — Roll back everything including data files
```bash
git checkout a7bf1e3 -- calc_swap_implied/calculate_swap_implied_rates.py post_to_roam.py output_master_1m.xlsx output_master_3m.xlsx output_master_6m.xlsx
git commit -m "Rollback: revert all 2026-03-28 Hedging_Cost_bps changes"
```

### Option C — Full hard reset to pre-change commit (nuclear)
Only if Options A/B are insufficient. This discards ALL commits after `a7bf1e3`.
```bash
git reset --hard a7bf1e3
git push --force origin main
```
**Warning:** This permanently removes the hedging cost commit from history.

## What breaks if the pipeline fails

- If `post_to_roam.py` breaks: implied rates are still calculated and saved to `output_master_*m.xlsx` — only Roam posting is affected. Roll back `post_to_roam.py` alone.
- If `calculate_swap_implied_rates.py` breaks: the calculation step fails. Roll back this file alone.
- Both scripts are independent — rolling back one does not affect the other.

## Key formula (for reference)
```
SOFR_ACT365      = USD_SOFR_{x}M_Pct × (365 / 360)
Hedging_Cost_bps = (Implied_SGD_Rate_Pct − SOFR_ACT365) × 100
```
`Rate_Diff_bps` (legacy) is unchanged: `(Implied_SGD_Rate_Pct − SOFR_ACT360) × 100`
